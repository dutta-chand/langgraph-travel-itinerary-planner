# AI Travel Itinerary Planner

A LangGraph-powered travel itinerary planner built with Python.

## Features

- LangGraph workflow
- Groq LLM integration
- Weather-aware itinerary generation
- Budget planning
- JSON output storage

## Tech Stack

- Python
- LangGraph
- Groq
- OpenWeatherMap API

## Workflow

Input
↓
Budget Planner
↓
Weather Fetcher
↓
AI Itinerary Generator
↓
Validation
↓
JSON Output

## Installation

pip install -r requirements.txt

## Run

python app.py
